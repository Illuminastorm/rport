# Portfolio

A minimal portfolio website with clean, square-based design and muted color palette.

## Features

- **Square Design**: No rounded corners, all geometric shapes
- **Muted Colors**: Grayscale and neutral tones only
- **Responsive**: Works on desktop and mobile devices
- **Minimal**: Focus on content and structure

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

This will start a local server at `http://localhost:8080` and automatically open your browser.

## Production

```bash
npm start
```

Starts the server without opening the browser.

## Sections

- **Header**: Title and tagline
- **Navigation**: Main navigation menu
- **About**: Brief introduction
- **Projects**: Portfolio project showcase (4 projects)
- **Skills**: Key skills and expertise
- **Contact**: Contact information
- **Footer**: Copyright information
